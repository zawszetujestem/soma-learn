SOMA Learn

SOMA Learn to nowoczesna platforma edukacyjna dla uczniów oparta o framework pracy własnej SOMA (Self-Organized Micro Agile).

Aplikacja pomaga uczniom rozwijać wiedzę poprzez:

krótkie sprinty nauki,
planowanie celów,
adaptacyjne ścieżki rozwoju,
współpracę uczeń ↔ nauczyciel ↔ AI,
gamifikację i system postępów.

Projekt początkowo skupia się na nauce matematyki dla polskich uczniów, ale architektura systemu została zaprojektowana z myślą o rozszerzeniu na kolejne przedmioty oraz pełnego asystenta AI wspierającego edukację.

Czym jest SOMA?

SOMA (Self-Organized Micro Agile) to framework inspirowany metodologiami Agile i Scrum, zaprojektowany do pracy indywidualnej oraz nauki.

Framework opiera się na:

mikro-sprintach,
iteracyjnym rozwoju,
regularnej refleksji,
adaptacyjnym planowaniu,
budowaniu samodzielności ucznia.
