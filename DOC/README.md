# Dokumentacja projektu soma-learn

Ten folder zawiera wstępne dokumenty opisujące projekt, jego założenia i proces tworzenia.

## Zawartość

- `PROJECT.md` – opis projektu, cele, zakres i wstępny plan,
- `AGENTS.md` – opis agentów i ich ról,
- `diagram.mmd` – diagram przepływu pracy agentów,
- `agents/` – szczegółowe opisy każdego agenta.

## Cel dokumentacji

Dokumentacja ma być centralnym źródłem wiedzy o projekcie, wspierać współpracę zespołu oraz ułatwiać wdrożenie kolejnych funkcjonalności.

## Jak korzystać

1. Przeczytaj `README.md` projektu, aby poznać ogólną wizję.
2. Zapoznaj się z `soma/README.md`, aby zrozumieć framework SOMA.
3. Otwórz `PROJECT.md`, aby poznać aktualny zakres i priorytety.
4. Przejdź do `AGENTS.md` i `agents/`, gdy chcesz sprawdzić role i odpowiedzialności w zespole.

## Linki

- `../soma/README.md` – framework SOMA,
- `README.md` – główny opis projektu.
